# Site Inventory: `youandinotai.com` — Current Live Surface (2026-11-04)

**Target URL studied**: `https://youandinotai.com/`  
**Surface role**: Marketing site and public entry point for Joshua Coleman's human-first dating, meetups, and real-world social connection platform (`youandinotai.com`, which is not for sale).  
**Backend & payments architecture (unchanged)**: Payments are processed exclusively through account-bound **Square** checkout; the application backend runs on **Google Cloud Run** behind `api.youandinotai.com`.  
**Method**: Headless Playwright inspection (`1920×1080` desktop viewport, `4,382 px` total scroll height; `390×844` mobile viewport, `6,835 px` total scroll height), computed-style telemetry, interactive modal extraction (`Terms of Service`, `Privacy Policy`, `Age Policy`, `Refund Policy`), SPA route inspection (`/support`), and network payload audit (`12` requests, `1,193,511 bytes` / `1.19 MB`).

## 2. Typography, Colour Palette, and Motion as Measured

### 2.1 The `Space Grotesk` vs. `font-sans` Override Bug

Inspecting `document.body` vs. the React root wrapper (`#root > div.font-sans`) reveals an unintended font override across the entire live landing page:

1. `index.html` loads `https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;700;900&display=swap` (`3,864 B` CSS + `22,288 B` `.woff2` binary), and `body` sets `font-family: "Space Grotesk", sans-serif` alongside a warm light-cream background (`rgb(244, 239, 230)` / `#F4EFE6`) and orange radial gradients (`rgba(255, 79, 0, 0.12)`).
2. However, the top-level React container in `JL()` applies Tailwind's `.font-sans` utility (`className="relative min-h-screen bg-zinc-950 text-zinc-300 font-sans ..."`). In Tailwind CSS v4 (`index-CG-2xOOU.css`), `.font-sans` resolves to `ui-sans-serif, system-ui, sans-serif, "Apple Color Emoji", "Segoe UI Emoji", "Segoe UI Symbol", "Noto Color Emoji"`.
3. **Result**: Every single headline (`H1`, `H2`, `H3`, `H4`), paragraph, nav link, and button inside the main page renders in generic `system-ui` instead of `Space Grotesk`. Only the `Cookie controls` banner (`div.z-[10001]`, which mounts as a sibling outside `.font-sans`) inherits `Space Grotesk` from `body`.

## 4. Verdict: What Is Good, What Is Ordinary, and What the House Look Replaces

### 4.1 What Is Good (Keep and Elevate)

1. **Product-First Launch Architecture**: The page puts the real product mechanics front and center: the `$1` Bot-Shield human checkpoint (`/app/verify`), the five account-bound Square checkout tiers (`/app/checkout/*`), and the live vs. waitlist `Launch Status` card.
2. **Explicit Account-Bound Square Pricing**: Visitors do not have to guess what membership costs or how billing works. All five tiers (`$1` Bot-Shield Verification, `$14.99/mo` Founding Member, `$39.99` 3-Month Founder, `$99.99` 12-Month Founder, and `$2,500` Royalty Card) are laid out plainly with direct routes into the authenticated checkout flow.
3. **Honest Capability Disclosures**: The `Launch Status` card clearly distinguishes what is `Live` (`Bot-Shield Flow`, `Founder Checkouts`) from what is `Waitlist` (`Profiles & Social`), and the `Age Policy` modal states honestly that the launch flow requires `18+` eligibility and a live camera + Square checkpoint without claiming production government-ID scanning before it is wired.
4. **Self-Contained Policy Modals, Support Routing & Privacy-First Cookies**: All four policies (`Terms of Service`, `Privacy Policy`, `Age Policy`, `Refund Policy`) open instantaneously in-page, `/support` provides clear paths for signed-in tickets (`/app/support`) and email escalation (`contact@youandinotai.com`), and the cookie banner defaults to minimal session cookies with zero ad-network trackers.

### 4.2 What Is Ordinary or Broken Today

1. **Generic Tailwind Dark-Card Template**: Every section relies on standard `rounded-3xl border-white/10 bg-white/5` glass boxes over blurred `yellow-600/20` and `amber-600/10` blobs and multi-stop gradient washes (`from-yellow-500/20 via-amber-500/20 to-stone-500/20`), which `docs/house/DESIGN-SYSTEM.md` explicitly forbids (*"No purple. No brown-red. No gradient washes."*).
2. **`Space Grotesk` Overridden by `system-ui`**: As proven in Section 2.1, `.font-sans` overrides `body`'s `"Space Grotesk"`, leaving the entire landing page in generic `system-ui` while still paying the network cost to download `Space Grotesk`.
3. **Search-and-Replace `tranzinc` CSS Bug**: Replacing `slate` with `zinc` corrupted `translate` into `tranzinc` (`hover:-tranzinc-y-0.5`, `group-hover:tranzinc-x-1`, `-tranzinc-y-1/2`), breaking button hover motion and misaligning the waitlist email icon.
4. **Dead `#trust` Navigation Link & Missing `Section 04`**: The top navbar links to `#trust` (`Trust`), and section numbering jumps from `Section 03 // Founder Pricing` to `Section 05 // Join`. Visitors clicking `Trust` get a dead link, and the platform's safety, moderation, and verified notification paths (`specs/006-mission-control-jarvis/spec.md`) have no dedicated section on the landing page.
5. **Clashing Light-Mode Neubrutalist Toggle Button**: A `44×44 px` cream-and-black neubrutalist theme toggle (`bg-[#fffaf2] border-[3px] border-[#111111] shadow-[4px_4px_0_0_rgba(17,17,17,1)]`) sits inside the dark glass top navbar next to the rounded pill CTA, left over from an earlier light-cream stylesheet (`body { background-color: rgb(244, 239, 230) }`).
6. **Sub-Floor Typography (`12 px` and `14 px` Copy)**: Verification step descriptions (`14 px`), pricing tier descriptions (`14 px`), section kickers (`12 px`), and footer/pricing captions (`12 px`) fall below the House's `20 px` desktop body standard and `16 px` minimum readable floor (`14 px` is permitted only for `Slate #9DA3AA` captions).
7. **Broken `/noise.png` Request & Colliding Bottom Bars**: `/noise.png` serves an HTML document (`200 OK`, `text/html`), and the fixed bottom CTA bar (`z-[9999]`) stacks underneath the `380 px`-tall cookie banner (`z-[10001]`).
8. **Missing House Title & Tribute**: Neither **`CLAUDE's N Joshua's`** nor **`#TeamClaudeForLife`** appears anywhere on the current `youandinotai.com` surface.
