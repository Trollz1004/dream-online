# Character Creation Vision

Status: design draft, updated 2026-11-03 for the founder's ruling that the creator shapes a body only.

## Goal

Character creation should make a player feel like they are entering a dangerous dream,
not filling out a form. The first version can be simple, but the direction should support
strong identity, class fantasy, and later console-friendly controls.

## The creator shapes a body only

- Body silhouette.
- Face preset.
- Skin tone.
- Hair shape.
- Hair color.
- Eye style.
- Voice style.

There are no outfits inside the creator. Everyone leaves the creator in kid-safe basics,
the same plain set for every character, so no player enters the world in anything but
kid-safe clothing. The wardrobe is the NEEDs shop (`docs/gdd/12-wardrobe-needs-shop.md`).

## Starter paths (picked in the same flow, not part of the body)

- Starter combat path.
- Starter life-skill interest.

## Starter combat paths

Starter paths should teach play style without locking the final identity too early.

- Blade path: fast melee, dodge, pressure.
- Hammer path: heavy melee, stagger, commitment.
- Spear path: reach, spacing, controlled engage.
- Bow path: range, positioning, weak-point timing.
- Focus path: projectile and field-control direction.

## Level identity beats

- Level 20: first expressive combat shift and wider AOE/group-pull potential.
- Level 45: prestige awakening.
- Nightmare Class: dark melee assassin identity.
- DREAM Class: mage/projectile identity.

## Visual evolution

Level 45 should visibly alter the character:

- Silhouette.
- Idle stance.
- Combat trails.
- Skill effects.
- UI frame.
- Social read from a distance.

## Console-friendly UX

- Large readable preview.
- Few choices per screen.
- Quick rotate and zoom.
- Preset-first, deep edit second.
- No tiny sliders required for first playable.
- Clear before/after preview for awakening visuals.

## Monetization boundary

Cosmetics and convenience only, sold through the NEEDs shop, never inside the creator.
Paid items must not sell combat power.

## Prototype acceptance

First playable character creation can be data-only:

- Five starter paths.
- Ten appearance presets.
- Two voice styles.
- One kid-safe basics set shared by every character.
- Stored profile JSON.
- Future awakening preview placeholders.
