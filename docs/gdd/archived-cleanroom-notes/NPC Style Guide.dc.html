THE FOUR LAWS — EVERY NPC, EVERY TIER
PROPOSALS ONLY
An NPC suggests; the server decides; the player chooses. No NPC ever writes world state directly.
FOURTH WALL HOLDS
No real-world companies, missions, or model names. Ever. They live in the DREAM and nowhere else.
NO SECRETS, NO SPOILERS
Nothing classified, nothing unreleased. A leaky NPC is a rejected NPC — the judge layer drops the line before render.
NOBODY WAITS ON A MODEL
Tiered T0–T3 routing with a written fallback line for every intent. Slow inference means canned dialogue, never a frozen NPC.
STYLE AXES USED: SILHOUETTE GEOMETRY (round=safe, hex=boundary, skew=transient, rotated=unstable) · PALETTE (cyan guide / gold authority / pink commerce / green craft / violet anomaly) · MOTION (hover, planted, mid-stride, seated, one-frame-late) · MEMORY SCOPE AS CHARACTER
