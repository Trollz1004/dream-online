## Honest Notes on What Still Looks Wrong

1. **Test Mannequin Proportions vs. Sculpted Game Art:** `test-rigged-humanoid-walk-not-game-art.glb` is explicitly an engineering test asset generated by headless Blender (`ops/blender/generate-test-rigged-humanoid-not-game-art.glb`) from tapered capsule limb segments. While its knees, hips, spine, and elbows bend smoothly via 4-bone Linear Blend Skinning, its silhouette is still a banded armor mannequin with a cylindrical helm rather than a true `TripoSG`/Blender high-to-low-poly character sculpt with facial features, hands, hair, layered pauldrons, or cloth coat tails.
2. **Uniform Tiled UV Layout on the Test Asset:** The test asset's 256×256 BaseColor, Tangent-Space Normal, and packed ORM textures verify that tangent-space normal relief (rivets, fluted ribs, recessed seams) and metallic/roughness/AO channels shade properly under scene lights without clipping silver metal to white, but the same plate/trim/leather pattern tiles across the head, torso, and limbs instead of using a dedicated character UV atlas.
3. **30-Copy Crowd Grid Placement:** In `?crowd=30` mode (`sunken-bastion-30-copies-60fps.png`), the 6×5 crowd formation uses fixed courtyard grid coordinates, so several crowd members stand close to or partially intersect the static code-built heroes and courtyard rocks.
4. **Old Code-Built Heroes Still Present for Side-by-Side Comparison:** As requested, the four code-built heroes remain in the scene next to the walking GLB test model; the legacy code-built Knight's shield and sword on the left still exhibit the older bloom/highlight behavior, contrasting directly with the energy-conserving silver-steel and bronze PBR response on the new GLB test model in the center.
