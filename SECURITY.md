# Security Policy

## Supported state

DREAM ONLINE is an early private prototype. Treat all runtime, AI, economy, account,
marketplace, and payment-related work as security-sensitive.

## Report a vulnerability

Use GitHub private vulnerability reporting or contact the repository owner through
GitHub. Do not post exploit details publicly.

## Never commit

- API keys.
- `.env` values.
- Provider tokens.
- Private keys.
- OneDrive vault material.
- Classified plot material.
- Session logs containing credentials.
- Real player personal information.

## Sensitive systems

Extra review is required for:

- Marketplace logic.
- Item drops.
- PvP gear risk.
- Paid entitlements.
- NPC model routing.
- Player memory.
- Account identity.
- Remote deployment.
