# Dream ONLINE Vision

## Pitch

Dream ONLINE is a seamless open-world action MMO where players fight through skill-based command combat, build wealth through deep life skills, and watch a living world shift between wilderness by day and dream-city danger by night.

## Pillars

1. Real action combat, not tab-target rotation.
2. Life skills are main progression, not side chores.
3. The world changes on a real schedule.
4. PvP is dangerous but rule-bound.
5. Convenience can be sold; power cannot.

## Core Fantasy

The player is not only a fighter. The player is a worker, fisher, cook, hunter, trader, farmer, crafter, guildmate, explorer, and night-city risk taker.

## First Fun Hypothesis

If combat feels good in a small field, and the same field also supports gathering, fishing, crafting, durability repair, and a night-state event, the MMO foundation is real.

## Name/Domain Notes

Primary candidate: Dream ONLINE.

Domain routing candidate:

- `dream-online.net`: primary game site.
- `dream-online.store`: cosmetics, account services, founder packs.
- `dream-online.info`: wiki, guides, patch notes.
- `dream-online.org`: guild/community portal.

Trademark and storefront collision checks are required before public launch.
