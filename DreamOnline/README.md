# Dream ONLINE

Clean vertical-slice workspace for the Dream ONLINE MMO concept.

## Current Direction

Dream ONLINE is an open-world action MMO prototype with no-tab-target combat as the core. The first build is not the full MMO. The first build is a small Dream Field vertical slice that proves combat feel, life skills, durability, PvP flagging, NPC schedules, and day/night Dream Shift streaming.

## Workspace Rules

- Keep this separate from `C:\antigravity` and date-app operations.
- Build small, test constantly, and promote only what feels good.
- No pay-to-win systems.
- Paid systems are cosmetics and convenience only.
- All numbers are tuning hypotheses until playtested.
