# Contributing To DREAM ONLINE

DREAM ONLINE is in private early production. Contributions are welcome only through
approved tasks, issues, or direct founder assignment.

## Working rules

- Keep public-facing language player-readable: live-world open-world MMO, action combat,
  life skills, player-driven economy, marketplace, and world events.
- Do not use direct competitor name drops in active docs, task titles, prompts, or public copy.
- Do not use `sandbox` jargon in player-facing copy.
- Do not add charity, private accounting, split, ownership, vendor/TOS, or real-world brand
  language to game-facing content.
- Do not read, commit, or expose secrets.
- Do not use classified OneDrive plot material in repo files.
- Do not add paid power. Monetization is convenience, style, access, storage, pets, runners,
  and similar boundaries only.

## Contribution types

- Design docs and GDD slices.
- Prototype backend code.
- Data contracts.
- Tooling and local development scripts.
- UI/UX wireframes.
- Original brand assets.
- Research notes with sources.

## Pull request standard

Every pull request should include:

- What changed.
- Why it matters.
- Files touched.
- Testing or validation performed, if any.
- Risk notes, especially for economy, PvP, monetization, AI, or public copy.

## Commit style

Use simple conventional commits:

- `docs:`
- `feat:`
- `fix:`
- `chore:`
- `test:`
- `refactor:`
