# CLAUDE.md - DREAM ONLINE Agent Guide

This repo is the clean DREAM ONLINE project home.

## Project language

Use player-readable terms:

- live-world open-world MMO
- action combat
- life skills
- player-driven marketplace
- Nightfall
- Nightmare Class
- DREAM Class
- Storage Runner
- Market Runner

Avoid:

- direct competitor name drops
- real-world brand names for in-game systems
- sandbox jargon in player-facing copy
- private accounting, split, charity, vendor/TOS, or unrelated business-platform language
- classified OneDrive plot material
